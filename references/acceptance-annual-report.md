# 建设验收文件与年度合规管理工作报告

## 一、共同规则

这两类文件以企业名义出具，采用企业公文报告文体（见 [writing-style.md](writing-style.md)）。律师是起草协助者，不在文中出现“本所”。

所有事实、数据、会议、培训、检查、考核和整改情况必须来自企业提供的材料或本项目已有成果；没有材料的部分以“【待企业提供：……】”占位，交付说明中逐项列出。

不得写“圆满完成”“显著提升”等无依据的评价；成效用可核实的事实表述，例如“制定或修订制度[数量]项”“开展培训[次数]次，覆盖[人数]人”。

## 二、合规管理体系建设工作报告（验收用）

默认结构：

1. 建设背景和依据；
2. 组织领导与工作过程：按时间写主要节点，依据会议纪要和项目文件；
3. 建设成果：组织、制度、运行机制、风险库、文化培训、合规检查，逐项列出成果名称、审议或发布情况；
4. 存在的不足；
5. 下一步工作安排。

附佐证材料目录：成果名称、审批或发布文件、日期、存放位置。目录只列已经存在的材料，缺少的以占位符标示。

上级国资或企业有验收标准或评分表的，逐项对照，写明对应的佐证材料。

## 三、年度合规管理工作报告

默认结构：

1. 年度合规管理工作总体情况；
2. 组织体系和制度建设情况；
3. 合规风险识别评估和重大合规风险应对情况；
4. 合规审查情况；
5. 合规检查、违规问题整改和问责情况；
6. 合规培训和文化建设情况；
7. 合规考核评价情况；
8. 存在的问题和原因；
9. 下一年度工作计划。

报告应当提交董事会审议，按规定报送上级国资监管机构。合规年度报告可以与风险管理、内部控制、法治建设等报告合并编写的，按企业惯例和上级要求处理。

报告所属年度与合同期限不一致的，在交付说明中提示律师。
