# 成稿转换规范

## 一、何时转换

只有律师确认某项成果定稿并下达转换指令后才转换。转换后 DOCX 或 XLSX 为有效稿，Markdown 归档不再更新；此后修改在成稿上进行，保留律师和企业的批注、修订。

征求意见稿需要发给企业的，按律师指令转换，并在文件名中保留“征求意见稿”字样。

## 二、版式

律师或企业提供格式蓝本的，以蓝本为准；企业有制度格式样本的，制度类成果按样本。未提供时：

1. 律师分析文书：沿用法律尽职调查技能的报告版式。正文楷体，西文和数字用 Times New Roman，小四，固定行距 22 磅，首行缩进 2 字符；标题 18 磅加粗居中；章标题 12 磅加粗居中；
2. 企业制度条文和企业公文报告：参照党政机关公文格式国家标准（GB/T 9704-2012）的通行做法，A4 纸；标题小标宋体二号居中；正文仿宋三号，固定行距约 28 磅；一级标题黑体，二级标题楷体；章名居中，条文“第×条”可加粗或用黑体；页码居中或外侧；
3. 宣贯材料：可以适当放宽，但全文黑色，不用彩色底纹和装饰图片，除非律师要求；
4. 表格类成果：转换为 XLSX，见第四节。

## 三、DOCX 转换流程

与尽调技能相同：

1. 转换前完成 [quality-gates.md](quality-gates.md) 的质量检查；
2. 删除内部区块；
3. 生成方式依次为：环境中可用的文档技能或工具；`pandoc` 加样式参考文档；`python-docx`；
4. 转换为 PDF 逐页核对，不得只抽查首尾页。

## 四、XLSX 转换

适用于合规风险库、职责清单、废改立清单、实施工作计划表、整改台账模板。用 `openpyxl` 生成：

1. 每个领域或部门一个工作表，或一个总表加“领域”列，由律师决定；
2. 首行为字段名并冻结，字段名加粗；
3. 列宽适配，单元格自动换行、顶端对齐，中文字体统一；
4. 风险等级列使用数据验证限定为“高”“中”“低”；
5. 不使用彩色填充，除非律师要求按等级着色；
6. 客户版删除“来源”列；
7. 转换后重新打开文件，核对行数与 Markdown 一致。

## 五、转换核对清单

字体字号、标题层级、序号连续、无 Markdown 残留符号、表格完整、无英文残留、占位符已按律师意见处理、文件名与成果对照一致。
