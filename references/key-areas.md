# 重点领域、重点环节、重点人员与专项合规制度

## 一、重点的选择

重点领域的选择依据：

1. 企业主营业务和资产结构；
2. 监管关注度；
3. 风险库评估结果（高风险集中的领域）；
4. 已发生的违规事件、处罚、诉讼和审计巡察发现；
5. 企业管理层的关注。

合同对重点领域数量有上限的，严格遵守。选择结果由律师和企业确认，记入体系设计基准第 11 项。诊断第七章写明每个候选领域的选择理由和放弃理由。

## 二、常见的候选领域

以下仅作提示，不累计适用：公司治理与“三重一大”决策；投资管理；招标采购；市场交易与大宗贸易；合同管理；资产交易和处置、租赁性资产管理、土地资产管理；工程建设；财务税收与资金管理；劳动用工；安全生产；生态环保；产品质量与食品安全；数据与信息安全；知识产权；反商业贿赂与廉洁从业；反垄断与反不正当竞争；关联交易；商业伙伴管理；境外经营。

地方国资文件列有重点领域的，以对本企业适用或参照的文件为准。

## 三、重点领域的深度要求

每个重点领域应形成：

1. 领域风险分析（业务流程、风险库条目、现有制度和控制）；
2. 管控要求和措施；
3. 专项制度或对现有业务制度的修订方案；
4. 合规审查要点；
5. 培训要点；
6. 检查要点。

非重点领域在风险库和员工合规行为规范中覆盖主要风险即可，不写专项制度。

## 四、重点环节和重点人员

重点环节：制度制定、经营决策、生产运营等环节，写明各环节的合规控制点。

重点人员：管理人员；重要风险岗位人员，由风险库中高风险对应的岗位确定，列出岗位名称而非个人；境外人员，仅在适用时。

## 五、专项合规制度的写法

按 [policy-drafting.md](policy-drafting.md) 的条文体例起草。专项制度不重复基本制度已规定的组织和通用机制，只写本领域的特有要求：适用的业务和流程、禁止性行为清单、关键控制点和审查要点、留痕要求、责任部门和问责。

优先以修订现有业务制度的方式实现；确需新立的，写明与现有业务制度的分工。

## 六、示例：大宗贸易领域的关键控制点（虚构示例，仅示范写法）

甲集团所属乙公司开展大宗贸易业务。关键控制点围绕交易真实性展开：

1. 交易对手准入时核验其资信状况，并查明其与本集团、供应商和客户之间是否存在关联关系；
2. 每笔交易须取得货权凭证、物流和仓储单据，业务部门负责人核对资金流与货物流是否一致，不一致的不得付款；
3. 不得开展无实物流转的融资性贸易和循环贸易；
4. 上下游为同一主体或其关联方的交易，业务部门应当在立项时报告，由合规管理牵头部门审查后提交决策；
5. 单笔和累计交易规模按金额分级设置审批权限，具体门槛由[企业决策机构]确定；
6. 合规管理牵头部门每[季度]对已完成交易按[比例]抽查，抽查记录归档。

示例中不出现真实企业名称和数据。执行时须核验国资监管关于贸易业务的现行规定，并以企业实际业务流程替换上述控制点。
