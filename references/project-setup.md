# 项目建立与体系设计基准

## 一、何时建立项目

收到委托合同、企业基础材料或律师的项目说明后，项目尚无工作底稿的，先建立工作底稿，再开始任何成果的起草。已有工作底稿的，直接读取，不重建、不另建副本。

## 二、工作底稿

文件名：`[企业简称]合规管理体系建设工作底稿.md`，放在律师指定的项目目录。工作底稿是内部文件，不向企业交付。

文首依次包含：

1. 项目信息：委托人全称、体系覆盖范围、企业的国资监管层级（中央、省属、市属、区属或其所属企业）、委托合同名称和签署情况、合同期限及起算日、经办律师、材料截止日；
2. 醒目标识“内部工作文件，请勿对外使用”；
3. 体系设计基准区（本文件第三节）；
4. 成果对照区（本文件第四节）；
5. 定义与写作约定区（本文件第五节）；
6. 规范依据核验记录区（格式见 [regulatory-basis.md](regulatory-basis.md) 第三节）；
7. 现状诊断各章空标题（章节见 [diagnosis.md](diagnosis.md) 第二节）；
8. 合规检查记录（开展检查时再建，见 [inspection.md](inspection.md) 第三节）。

尚未开展的部分只保留标题，不预填空表和检查项。

## 三、体系设计基准区

体系设计基准是本项目所有成果共同遵守的设计决定。每一项写明：事项、决定内容、状态、确认情况、影响的成果。

状态只有两种：

- “建议”：模型根据诊断提出的建议选项，尚未经律师确认。可以写两至三个选项并说明利弊；
- “已确认”：律师已经确认（必要时已与企业确认）。写明确认日期和方式，例如“律师于[日期]在对话中确认”“企业于[日期]项目会议确认”。

默认事项如下，按项目实际增删：

1. 体系覆盖范围：仅本部，或本部及全资、控股子企业；所属企业的管控方式；
2. 规范适用关系：对本企业直接适用的国资监管文件，以及参照的文件（见 [regulatory-basis.md](regulatory-basis.md) 第一节）；
3. 党组织在合规管理中的作用：党委（党组）研究讨论合规管理重大事项的范围和方式；
4. 董事会层面的合规管理机构：单设合规委员会，或由审计委员会、风险管理委员会等现有专门委员会承担，或不设而由董事会直接承担；
5. 监督机构：监事会，或董事会审计委员会行使监事会职权，以企业现行章程为准；
6. 合规管理负责人：由总法律顾问、首席合规官或其他高级管理人员担任；
7. 合规管理牵头部门，及其与法务、风控、内控、审计、纪检部门的分工；
8. 业务及职能部门的合规联络员或兼职合规管理员设置；
9. 三道防线的划分；
10. 合规审查的嵌入方式（与法律审核合一，或单设审查节点）及必审事项范围；
11. 重点领域（数量受合同约束）、重点环节、重点人员的范围；
12. 合规风险评估标准：可能性和影响的分级及等级划分（默认标准见 [risk-assessment.md](risk-assessment.md) 第四节）；
13. 制度层级与命名规则、制度文号和格式样本；
14. 制度审批路径：党委前置研究、董事会审议、经理层批准、职工民主程序、报上级备案的范围；
15. 合规报告的路线和频次；
16. 合规考核评价与现有绩效考核的挂钩方式；
17. 违规举报渠道及受理部门；
18. 境外合规要求是否适用；
19. 合规管理信息化的实现方式（现有系统嵌入、新建模块或暂不建设）；
20. 企业名称、简称及各机构、部门的标准名称。

规则：

1. 起草任何成果前，先读本区；成果中出现的机构、职务、部门、领域、等级、制度名称，必须与本区一致；
2. 依赖“建议”状态事项的成果，只能起草为征求意见稿，在文件标题后注明“（征求意见稿）”，并在交付说明中列出所依赖的未确认事项；
3. 律师确认或变更某项基准时，在本区更新该项，并列出受影响的已完成成果，在对话中报告；未经律师指令，不回改已完成成果；
4. 不在其他位置另行记录设计决定，避免两处口径不一。

## 四、成果对照区

成果对照把委托合同约定的服务内容和成果，对应到具体的成果文件。每项写明：编号、合同依据（条款号）、成果名称、文件名、文体（见 [writing-style.md](writing-style.md) 第一节）、依赖的基准事项、状态。

状态只有：未开始、征求意见稿、律师审定、已转换成稿。每轮交付时同步更新本区对应一行，不另建进度台账。

常见委托合同的成果，可以按以下方式对应（按合同实际调整，不得增加合同没有约定的成果，除非律师要求）：

| 成果类别 | 成果文件 |
|---|---|
| 现状分析与计划 | 合规管理现状诊断报告；合规管理体系建设计划方案（含重点建设方案）；实施工作计划表；年度合规管理工作计划模板；主要合规风险识别、评价及控制方案 |
| 组织体系 | 合规管理组织体系构建方案；合规管理职责清单 |
| 制度体系 | 合规管理制度体系构建方案（含现行制度废改立清单）；合规管理办法；员工合规行为规范；重点领域专项合规制度 |
| 运行体系 | 各项运行机制制度（合并方式见 [operating-mechanisms.md](operating-mechanisms.md) 第二节）；合规风险库 |
| 合规文化 | 合规手册；合规承诺书；培训方案、课件与讲稿 |
| 合规检查 | 合规检查方案；合规检查整改意见书；整改情况复核意见 |
| 验收与报告 | 合规管理体系建设工作报告及佐证材料目录；年度合规管理工作报告 |

合同列举的机制或成果存在重复、缺项或表述不清的，在成果对照中写明处理方式（例如两项合并为一份制度），并在对话中报告律师，由律师决定是否向企业说明。

## 五、定义与写作约定区

记载本项目选定的称谓和格式，每轮起草前读取，新设简称随即补录：

- 企业全称和各文体中的称谓（制度中称“公司”或“集团公司”，律师文书中的定义简称，公文报告中的自称）；
- 上级单位、监管机构的标准称谓；
- 各机构、部门、职务的标准名称（与体系设计基准第 20 项一致）；
- 日期、金额、序号格式；
- 尽调文件称谓与本项目称谓的对应关系（如尽调文件中的“标的公司”）。

## 六、建设计划方案、实施工作计划表和年度计划模板

建设计划方案是律师分析文书，以现状诊断为基础，通常写明：建设目标、依据和适用关系、覆盖范围、总体思路（含与现有风控内控体系的融合）、重点建设内容（组织、制度、机制、重点领域、文化、检查）、成果清单、阶段安排、双方分工与企业配合事项、需要企业决策的事项。合同要求“重点建设方案”的，在本方案中设专章，写明各重点领域的建设内容，或者单独成文，由律师决定。

实施工作计划表是表格类成果，列明：阶段、工作事项、成果、牵头方、配合方、计划完成时间、企业决策节点。时间安排以合同期限为限，不写入费用和付款节点。

年度合规管理工作计划模板是供企业此后每年使用的模板，按年度工作的固定板块（组织、制度、风险识别、审查、检查、培训、考核、报告）设栏目，具体内容以“【由企业按年度填写：……】”标示，可附填写说明。

## 七、建立项目当轮的对话输出

建立工作底稿的当轮，在对话中（不落盘）给出：

1. 材料与诊断章节的归类总览；
2. 体系设计基准中可以依据现有材料先行提出建议的事项，以及必须由律师或企业确认的事项；
3. 合同条款中重复、缺项、范围不清或可能产生履约争议的地方；
4. 建议的成果起草顺序。
