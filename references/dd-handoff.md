# 与法律尽职调查技能的衔接

## 一、分工

法律尽职调查技能（`legal-due-diligence`）回答的问题是：企业的经营行为是否合法，存在哪些法律风险。它面向截至基准日的现状，对象是主体、股权、治理、资产、合同、财税、劳动、债务、诉讼处罚等事实，产出底稿、尽调报告和重大问题清单。

本技能回答的问题是：企业管理合规风险的体系是否健全，应当如何建设，建成后如何证明在运行。它既诊断现状，也面向未来作设计，对象是组织、制度、机制、文化和重点领域管控措施，产出诊断报告、各类方案、制度、风险库、手册、检查整改意见、验收与年度报告。

两者是上下游关系，不重复做同一件事。本技能不重做尽调，不改动尽调底稿、尽调报告和重大问题清单；只读取其中已经形成的结论，并按本文件规则转化使用。

## 二、读取范围

优先读取顺序：已交付的尽调报告，其次是重大问题清单，再次是经律师审阅的尽调底稿。读取各章的“初步结论与风险”“律师意见”或“结论与风险提示”部分，必要时回读事实段，核对事实依据。

尚未经律师审阅的底稿内容，只能作为线索，不能直接写入客户文件。

## 三、尽调章节与合规用途的对应

| 尽调章节（默认十章） | 在合规体系建设中的主要用途 |
|---|---|
| 一、公司基本信息与主体资格 | 经营资质和许可类合规义务；超范围经营风险 |
| 二、股权结构与股东信息 | 国有产权管理、出资和产权登记类合规义务 |
| 三、公司治理与组织结构 | 诊断第二章（领导作用与组织体系）；“三重一大”决策和授权体系 |
| 四、核心资产 | 土地资产、租赁性资产、国有资产交易和处置领域 |
| 五、业务经营与重大合同 | 合同管理、市场交易、招标采购、大宗贸易、关联交易领域 |
| 六、财务与税务 | 财务税收领域 |
| 七、劳动人事 | 劳动用工领域 |
| 八、重大债权债务与担保 | 投融资、担保、资金往来领域 |
| 九、诉讼、仲裁与行政处罚 | 已发生的违规事件；风险可能性评估的依据；培训案例（脱敏） |
| 十、其他重要事项 | 安全生产、生态环保、数据合规、反商业贿赂等领域 |

尽调章节按项目调整的，以实际章节为准，按同样思路对应。

## 四、转化步骤

1. 列出尽调文件中已认定的每一项风险或问题；
2. 区分“具体事实”（某一合同、某一批员工、某一处房产）与“可归纳的风险规律”（某类业务环节反复出现的同类问题）；
3. 判断管理成因：制度缺失、制度设计缺陷、执行不到位、职责不清、外部因素；
4. 归入诊断章节和风险领域；
5. 按本项目风险评估标准重新评级。尽调问题清单的等级以交易或项目目的为基准，不得机械换算为合规风险等级；
6. 确定去向：存量问题进入诊断报告或合规检查整改意见的整改建议；风险规律进入合规风险库、专项制度管控要求和合规审查要点；典型事件经脱敏后可作培训案例；可能涉及违纪违法的线索只报告律师。

转化结果写在工作底稿诊断第五章“重点领域合规风险”中，可以使用一张紧凑表格，列明尽调来源、事实摘要、成因、领域和去向，不另建文件。

## 五、来源标注

工作底稿中写明具体来源，如“尽调底稿第七章风险 3”“尽调问题清单二级第 4 项”。客户文件只引用已经交付企业的尽调报告，不引用内部底稿。合规风险库的内部版保留来源栏，客户版删除。

## 六、时间差与冲突

尽调基准日之后已有整改、变化或新材料的，以最新材料为准，并在工作底稿中说明。

与尽调文件的事实或判断不一致的，在对话中报告律师，由律师决定修改哪一份文件；本技能不回改尽调文件。

## 七、没有尽调文件时

可以独立依据材料和访谈完成诊断。诊断需要查明的具体法律事实超出合规体系诊断范围的，例如需要逐份审查土地权属或重大合同，提示律师是否先调用 `legal-due-diligence` 完成相应章节，不在诊断中代做尽调。

## 八、称谓转换

尽调文件中的“标的公司”等称谓，在本项目各文体中按工作底稿“定义与写作约定区”转换：制度条文称“公司”或“集团公司”，律师分析文书使用定义简称，企业公文报告使用企业自称。对应关系在项目建立时记录，此后全文统一。
