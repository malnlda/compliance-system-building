# compliance-system-building

面向中国企业（尤其是地方国有企业）合规管理体系建设项目的写作技能：以现状诊断和统一的体系设计基准为起点，按委托合同逐项起草各项交付成果，由律师逐项审定；可读取法律尽职调查结果并转化为合规风险、管控要求和整改意见；成果定稿后按律师指令转换为 DOCX 或 XLSX。

## 工作方式

```
项目建立（工作底稿 + 体系设计基准 + 成果对照）
   → 现状诊断（逐章）→ 诊断报告 → 律师与企业确认体系设计基准
   → 计划方案 → 组织体系与职责 → 制度体系 → 合规管理办法
   → 运行机制 → 合规风险库 → 行为规范与专项制度
   → 合规手册与培训 → 合规检查与整改 → 验收与年度报告
   → （律师指令后）转换为 DOCX 或 XLSX
```

核心约定：

- **律师主导。** 体系设计决定、重点领域、风险等级、成果是否定稿，均由律师决定。
- **一轮一项成果。** 一次对话只实质起草或深度修订一项成果，大型成果按领域分轮。
- **体系设计基准先行。** 机构、负责人、牵头部门、重点领域、风险等级等设计决定记录在工作底稿文首，所有成果严格遵从。
- **先诊断，后设计。** 设计安排都要能追溯到诊断发现或规范要求，不写通用条款。
- **不照搬范本。** 企业没有的机构和业务不得出现在成果中，除非基准决定新设。
- **不编造记录。** 企业没有提供的执行记录、会议纪要、培训签到和统计数据，一律用占位符标示。
- **依据须核验。** 引用的规范经检索核验现行有效，并区分“适用”和“参照”。
- **文体分明。** 律师分析文书、企业制度条文、企业公文报告、宣贯材料，各用各的写法。

## 与法律尽职调查技能的关系

法律尽职调查由 [legal-due-diligence](https://github.com/malnlda/legal-due-diligence) 承担，回答企业经营行为是否合法、存在哪些法律风险；本技能回答管理合规风险的体系是否健全、如何建设。两者是上下游关系：本技能只读取尽调底稿、报告和重大问题清单，把具体事实转化为整改建议，把风险规律转化为风险库条目和制度要求，不重做尽调，也不改动尽调文件。项目没有尽调文件的，本技能可以独立完成诊断。

## 使用示例

项目建立：

> 使用 $compliance-system-building 为[企业]的合规管理体系建设项目建立工作底稿。委托合同在……，材料在……，尽调底稿在……。

诊断：

> 使用 $compliance-system-building 诊断第二章“领导作用与组织体系”，材料在……。

起草制度：

> 使用 $compliance-system-building 按体系设计基准起草《合规管理办法》征求意见稿。

风险库：

> 使用 $compliance-system-building 起草合规风险库中“招标采购”领域的条目，参考尽调底稿第五章。
